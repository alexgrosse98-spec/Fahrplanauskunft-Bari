Digitale Fahrplanauskunft A1/A2 für iPhone

Die App ist als Progressive Web App erstellt.

Für die Installation auf dem iPhone:
1. Den Ordner über einen HTTPS-Webserver veröffentlichen.
2. index.html in Safari öffnen.
3. Teilen > Zum Home-Bildschirm.

Nach der ersten Installation funktioniert die App offline.

Hinweis: Die Fahrplandaten wurden aus einem klein gedruckten Scan rekonstruiert. Einzelne OCR-Fehler können enthalten sein.
